# Autonomous Fire Fighting Robot using ESP32-CAM

This project demonstrates an autonomous fire fighting robot built using ESP32-CAM.
The robot detects fire using a flame sensor and automatically activates a water pump
to extinguish it.

## Features
- Fire detection using flame sensor
- Autonomous movement
- Water pump activation
- ESP32-CAM for future live monitoring

## Components Used
- ESP32-CAM
- Flame Sensor
- L298N Motor Driver
- DC Motors
- Water Pump
- Relay Module
- Battery
